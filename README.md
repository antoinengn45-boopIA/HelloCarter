# # HelloCarter

Bienvenue sur le projet **HelloCarter**, une interface bancaire moderne et intuitive.

## Description
HelloCarter est une application web dédiée à la gestion financière personnelle. Ce projet a pour but de fournir une interface propre pour visualiser son solde et ses transactions.

## Fonctionnalités
- [ ] Visualisation du solde en temps réel
- [ ] Historique des transactions
- [ ] Interface responsive (mobile-friendly)

## Installation
1. Clonez ce dépôt : `git clone https://github.com/votre-utilisateur/HelloCarter.git`
2. Ouvrez `index.html` dans votre navigateur.

## Technologies utilisées
- HTML5
- CSS3
- JavaScript (Vanilla)
